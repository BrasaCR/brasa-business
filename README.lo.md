# BRASA Business

**ຊອບ​ແວ​ທຸ​ລະ​ກິດ​ຟຣີ​ແລະ​ຕະ​ຫຼາດ​ພົນ​ລະ​ເມືອງ—ຈັດ​ຕັ້ງ​ສໍາ​ລັບ​ການ​ຄ້າ​ທຸກ​ຄັ້ງ.**

[ເປີດ BRASA Business](https://brasa.business/) · [BRASA World](https://brasa.world/) · [ການສຶກສາ](https://brasa.education/) · [ລັດຖະບານ](https://brasagovernment.net/)

BRASA Business ໃຫ້​ພົນ​ລະ​ເມືອງ​ເຄື່ອງ​ມື​ພາກ​ປະ​ຕິ​ບັດ​ເພື່ອ​ເລີ່ມ​ຕົ້ນ​ການ, ດໍາ​ເນີນ​ການ, ແລະ​ຂະ​ຫຍາຍ​ຕົວ​ທຸ​ລະ​ກິດ. ເວທີດັ່ງກ່າວກວມເອົາຫຼາຍອາຊີບແລະຂະແຫນງການໃນຂະນະທີ່ຮັກສາປະສົບການທີ່ເຊື່ອມຕໍ່ກັບການສຶກສາ, ການບໍລິການຂອງລັດຖະບານ, ແລະຫນ້າປະເທດຂອງແຕ່ລະຄົນ.

## ສິ່ງທີ່ພົນລະເມືອງໄດ້ຮັບ

- ຊອບແວທຸລະກິດຟຣີທີ່ບໍ່ມີການທົດລອງຫຼືການສະຫມັກ
- ເຄື່ອງມືທີ່ປັບຕົວເຂົ້າກັບອາຊີບ ແລະຂະແໜງການຕ່າງໆ
- A BRASA ID ຜ່ານລະບົບການລະບຸຕົວຕົນຂອງພົນລະເມືອງທີ່ແບ່ງປັນ
- ການຈ່າຍເງິນລູກຄ້າໂດຍກົງແທນທີ່ຈະ BRASA ຖືກອງທຶນການຄ້າ
- ການເຊື່ອມຕໍ່ກັບການຮຽນຮູ້, ການບໍລິການສາທາລະນະ, ແລະຕະຫຼາດ BRASA ທີ່ກວ້າງກວ່າ

## ຫຼັກການປະຕິບັດການ

- BRASA ບໍ່ໄດ້ຄິດຄ່າພົນລະເມືອງເພື່ອເລີ່ມຕົ້ນການນໍາໃຊ້ຊອບແວທຸລະກິດ.
- ການລະບຸຕົວຕົນຖືກສ້າງຂື້ນໂດຍຜ່ານການບໍລິການລົງທະບຽນທີ່ແບ່ງປັນ.
- BRASA ບໍ່ໄດ້ນັ່ງຢູ່ໃນເສັ້ນທາງການຈ່າຍເງິນລະຫວ່າງທຸລະກິດແລະລູກຄ້າຂອງຕົນ.
- ການຮຽກຮ້ອງການຈ່າຍເງິນ, ພາສີ, ແລະໃບແຈ້ງໜີ້ສະເພາະປະເທດຕ້ອງຖືກກວດສອບກ່ອນການພິມເຜີຍແຜ່.
