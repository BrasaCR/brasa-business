# BRASA ವ್ಯಾಪಾರ

**ಉಚಿತ ವ್ಯಾಪಾರ ಸಾಫ್ಟ್‌ವೇರ್ ಮತ್ತು ನಾಗರಿಕ ಮಾರುಕಟ್ಟೆ-ಪ್ರತಿ ವ್ಯಾಪಾರಕ್ಕಾಗಿ ಆಯೋಜಿಸಲಾಗಿದೆ.**

[BRASA ವ್ಯಾಪಾರವನ್ನು ತೆರೆಯಿರಿ](https://brasa.business/) · [BRASA ವರ್ಲ್ಡ್](https://brasa.world/) · [ಶಿಕ್ಷಣ](https://brasa.education/) · [ಸರ್ಕಾರ](https://brasagovernment.net/)

BRASA ವ್ಯಾಪಾರವು ವ್ಯವಹಾರವನ್ನು ಪ್ರಾರಂಭಿಸಲು, ಕಾರ್ಯನಿರ್ವಹಿಸಲು ಮತ್ತು ಬೆಳೆಸಲು ನಾಗರಿಕರಿಗೆ ಪ್ರಾಯೋಗಿಕ ಸಾಧನಗಳನ್ನು ನೀಡುತ್ತದೆ. ಶಿಕ್ಷಣ, ಸರ್ಕಾರಿ ಸೇವೆಗಳು ಮತ್ತು ಪ್ರತಿಯೊಬ್ಬ ನಾಗರಿಕನ ದೇಶದ ಪುಟಕ್ಕೆ ಸಂಪರ್ಕ ಹೊಂದಿದ ಅನುಭವವನ್ನು ಇಟ್ಟುಕೊಂಡು ವೇದಿಕೆಯು ಅನೇಕ ವೃತ್ತಿಗಳು ಮತ್ತು ಕ್ಷೇತ್ರಗಳನ್ನು ಒಳಗೊಂಡಿದೆ.

## ನಾಗರಿಕರು ಏನು ಸ್ವೀಕರಿಸುತ್ತಾರೆ

- ಯಾವುದೇ ಪ್ರಯೋಗ ಅಥವಾ ಚಂದಾದಾರಿಕೆ ಇಲ್ಲದ ಉಚಿತ ವ್ಯಾಪಾರ ಸಾಫ್ಟ್‌ವೇರ್
- ವಿವಿಧ ವೃತ್ತಿಗಳು ಮತ್ತು ವಲಯಗಳಿಗೆ ಅಳವಡಿಸಲಾದ ಪರಿಕರಗಳು
- ಹಂಚಿದ ನಾಗರಿಕ ಗುರುತಿನ ವ್ಯವಸ್ಥೆಯ ಮೂಲಕ BRASA ID
- ವ್ಯಾಪಾರಿ ನಿಧಿಗಳನ್ನು ಹೊಂದಿರುವ BRASA ಗಿಂತ ನೇರ ಗ್ರಾಹಕ ಪಾವತಿ
- ಕಲಿಕೆ, ಸಾರ್ವಜನಿಕ ಸೇವೆಗಳು ಮತ್ತು ವಿಶಾಲವಾದ BRASA ಮಾರುಕಟ್ಟೆಗೆ ಸಂಪರ್ಕಗಳು

## ಕಾರ್ಯಾಚರಣೆಯ ತತ್ವಗಳು

- ವ್ಯಾಪಾರ ಸಾಫ್ಟ್‌ವೇರ್ ಅನ್ನು ಬಳಸಲು ಪ್ರಾರಂಭಿಸಲು BRASA ನಾಗರಿಕರಿಗೆ ಶುಲ್ಕ ವಿಧಿಸುವುದಿಲ್ಲ.
- ಹಂಚಿದ ಸೈನ್ ಅಪ್ ಸೇವೆಯ ಮೂಲಕ ಗುರುತನ್ನು ರಚಿಸಲಾಗಿದೆ.
- ವ್ಯಾಪಾರ ಮತ್ತು ಅದರ ಗ್ರಾಹಕರ ನಡುವಿನ ಪಾವತಿ ಮಾರ್ಗದಲ್ಲಿ BRASA ಕುಳಿತುಕೊಳ್ಳುವುದಿಲ್ಲ.
- ದೇಶ-ನಿರ್ದಿಷ್ಟ ಪಾವತಿ, ತೆರಿಗೆ ಮತ್ತು ಇನ್‌ವಾಯ್ಸ್ ಕ್ಲೈಮ್‌ಗಳನ್ನು ಪ್ರಕಟಣೆಯ ಮೊದಲು ಪರಿಶೀಲಿಸಬೇಕು.

## ಭಾಷಾ ಪ್ರವೇಶ

ಇಂಗ್ಲಿಷ್ ಉಳಿಸಿಕೊಂಡ ಮೂಲವಾಗಿ ಉಳಿದಿದೆ. ಪ್ರತಿ ಪ್ರಕಟಿತ ಅನುವಾದವು ತನ್ನದೇ ಆದ ಫೈಲ್ ಮತ್ತು ಸಾರ್ವಜನಿಕ URL ಅನ್ನು ಪಡೆಯುತ್ತದೆ ಆದ್ದರಿಂದ ನಾಗರಿಕರು ಇಂಗ್ಲಿಷ್ ಎಡಿಟಿಂಗ್ ಮಾನದಂಡವನ್ನು ಬದಲಾಯಿಸದೆಯೇ ತಮ್ಮ ಭಾಷೆಯಲ್ಲಿ BRASA ಅನ್ನು ಬಳಸಬಹುದು.

## ವ್ಯವಹಾರವನ್ನು ಪ್ರಾರಂಭಿಸಿ

ವೃತ್ತಿಗಳನ್ನು ಅನ್ವೇಷಿಸಲು ಮತ್ತು ನಿಮ್ಮ ಖಾತೆಯನ್ನು ರಚಿಸಲು [ಬ್ರಾಸ.ವ್ಯಾಪಾರ](https://brasa.business/) ಗೆ ಭೇಟಿ ನೀಡಿ.

## ನಿರ್ವಹಣೆ ಟಿಪ್ಪಣಿಗಳು

ಸೈಟ್ ಅನ್ನು ಸ್ಥಿರ HTML ಮತ್ತು JavaScript ಆಗಿ ನಿಯೋಜಿಸಲಾಗಿದೆ. ಗುರುತು, ಪಾವತಿಗಳು, ಇನ್‌ವಾಯ್ಸ್ ಅಥವಾ ದೇಶ-ನಿರ್ದಿಷ್ಟ ಅನುಸರಣೆಯ ಮೇಲೆ ಪರಿಣಾಮ ಬೀರುವ ಬದಲಾವಣೆಗಳಿಗೆ ಬಿಡುಗಡೆಯ ಮೊದಲು ಪರಿಶೀಲನೆ ಅಗತ್ಯವಿದೆ.

## BRASA ಇಂದು

BRASA ಈಗ 198 ದೇಶದ ತಾಣಗಳನ್ನು ಶಿಕ್ಷಣ, ಸರ್ಕಾರ ಮತ್ತು ವ್ಯಾಪಾರದೊಂದಿಗೆ ಸಂಪರ್ಕಿಸುತ್ತದೆ. BRASA Businessನಲ್ಲಿ 12 ಪರಸ್ಪರ ಸಂಪರ್ಕಿತ ಕ್ಷೇತ್ರಗಳಿವೆ: ಮಾರಾಟ ಮತ್ತು ರಸೀದಿಗಳು, CRM, ದಾಸ್ತಾನು, ಜನರು ಮತ್ತು ತರಬೇತಿ, ವೇತನ ಮತ್ತು ಬ್ಯಾಂಕಿಂಗ್, ಸಮಯ, ಕುಟುಂಬ ಬೆಂಬಲ, ಕಾನೂನು ಕೆಲಸ, ಸರ್ಕಾರಿ ನಮೂನೆಗಳು, ವರದಿಗಳು ಮತ್ತು ಹಂಚಿಕೆಯ ಕಾರ್ಯಕ್ಷೇತ್ರ. ಇದರಲ್ಲಿ ಮುಕ್ತ ಲೆಡ್ಜರ್, ಮಾರ್ಗದರ್ಶಿತ ಕಾರ್ಯಪ್ರವಾಹಗಳು ಮತ್ತು ಆಫ್‌ಲೈನ್ ನಿರಂತರತೆಯೂ ಸೇರಿವೆ.

BRASA Financials 395 ದಾಖಲೆಗಳಿಂದ 385 ಪಾವತಿ ವ್ಯವಸ್ಥೆಗಳನ್ನು ಪಟ್ಟಿ ಮಾಡುತ್ತದೆ; 161 ಮಾರುಕಟ್ಟೆ ವಿವರಣೆಗಳು ಮತ್ತು 216 ಪಾವತಿ ಪ್ರಕಾರಗಳು ಇವೆ: ಮೊಬೈಲ್ ಹಣ, ತ್ವರಿತ ವರ್ಗಾವಣೆ, QR, ವಾಲೆಟ್‌ಗಳು, ನಗದು ಜಾಲಗಳು, ಹಣ ರವಾನೆ, open banking, ದೇಶೀಯ ಕಾರ್ಡ್ ವ್ಯವಸ್ಥೆಗಳು ಮತ್ತು USSD.

ಪಟ್ಟಿಯಲ್ಲಿರುವುದು ಸಕ್ರಿಯವಾಗಿದೆ ಎಂದರ್ಥವಲ್ಲ. ಪರವಾನಗಿ ಪಡೆದ ಪೂರೈಕೆದಾರರು ಹಣವನ್ನು ವರ್ಗಾಯಿಸುತ್ತಾರೆ; ಪ್ರತಿಯೊಂದು ವಿಧಾನಕ್ಕೂ ದೇಶ ಮತ್ತು ಮೂಲ ಪರಿಶೀಲನೆ, ಪರವಾನಗಿ, ಏಕೀಕರಣ, ಸೆಟ್ಲ್‌ಮೆಂಟ್ ಪರೀಕ್ಷೆ ಮತ್ತು ಉತ್ಪಾದನಾ ಅನುಮೋದನೆ ಅಗತ್ಯ. BRASA ಪರಿಶೀಲಿತ ಆಯ್ಕೆಗಳನ್ನು ರಸೀದಿಗಳು, ಹೊಂದಾಣಿಕೆ ಮತ್ತು ಮುಕ್ತ ಲೆಡ್ಜರ್‌ಗೆ ಸಂಪರ್ಕಿಸುತ್ತದೆ.
