# BRASA ബിസിനസ്

**സൗജന്യ ബിസിനസ് സോഫ്‌റ്റ്‌വെയറും ഒരു സിറ്റിസൺ മാർക്കറ്റ്‌പ്ലേസും—ഓരോ കച്ചവടത്തിനും വേണ്ടി സംഘടിപ്പിച്ചിരിക്കുന്നു.**

[BRASA ബിസിനസ്സ് തുറക്കുക](https://brasa.business/) · [BRASA ലോകം](https://brasa.world/) · [വിദ്യാഭ്യാസം](https://brasa.education/) · [സർക്കാർ](https://brasagovernment.net/)

BRASA ബിസിനസ് പൗരന്മാർക്ക് ഒരു ബിസിനസ്സ് ആരംഭിക്കുന്നതിനും പ്രവർത്തിപ്പിക്കുന്നതിനും വളർത്തുന്നതിനുമുള്ള പ്രായോഗിക ഉപകരണങ്ങൾ നൽകുന്നു. വിദ്യാഭ്യാസം, സർക്കാർ സേവനങ്ങൾ, ഓരോ പൗരൻ്റെയും രാജ്യ പേജ് എന്നിവയുമായി ബന്ധിപ്പിച്ച അനുഭവം നിലനിർത്തിക്കൊണ്ട് പ്ലാറ്റ്ഫോം നിരവധി തൊഴിലുകളും മേഖലകളും ഉൾക്കൊള്ളുന്നു.

## പൗരന്മാർക്ക് ലഭിക്കുന്നത്

- ട്രയലോ സബ്‌സ്‌ക്രിപ്ഷനോ ഇല്ലാത്ത സ്വതന്ത്ര ബിസിനസ്സ് സോഫ്റ്റ്‌വെയർ
- വിവിധ തൊഴിലുകൾക്കും മേഖലകൾക്കും അനുയോജ്യമായ ഉപകരണങ്ങൾ
- പങ്കിട്ട പൗര തിരിച്ചറിയൽ സംവിധാനത്തിലൂടെയുള്ള ഒരു BRASA ഐഡി
- BRASA ഹോൾഡിംഗ് മർച്ചൻ്റ് ഫണ്ടുകളേക്കാൾ നേരിട്ട് ഉപഭോക്തൃ പേയ്‌മെൻ്റ്
- പഠനം, പൊതു സേവനങ്ങൾ, വിശാലമായ BRASA മാർക്കറ്റ് പ്ലേസ് എന്നിവയിലേക്കുള്ള കണക്ഷനുകൾ

## പ്രവർത്തന തത്വങ്ങൾ

- ബിസിനസ് സോഫ്‌റ്റ്‌വെയർ ഉപയോഗിക്കാൻ തുടങ്ങുന്നതിന് BRASA പൗരന്മാരിൽ നിന്ന് നിരക്ക് ഈടാക്കുന്നില്ല.
- പങ്കിട്ട സൈൻഅപ്പ് സേവനത്തിലൂടെയാണ് ഐഡൻ്റിറ്റി സൃഷ്ടിക്കുന്നത്.
- ഒരു ബിസിനസ്സിനും അതിൻ്റെ ഉപഭോക്താവിനും ഇടയിലുള്ള പേയ്‌മെൻ്റ് പാതയിൽ BRASA ഇരിക്കുന്നില്ല.
- രാജ്യം-നിർദ്ദിഷ്ട പേയ്‌മെൻ്റ്, നികുതി, ഇൻവോയ്‌സിംഗ് ക്ലെയിമുകൾ എന്നിവ പ്രസിദ്ധീകരിക്കുന്നതിന് മുമ്പ് പരിശോധിച്ചുറപ്പിച്ചിരിക്കണം.

## ഭാഷാ പ്രവേശനം

ഇംഗ്ലീഷാണ് പരിപാലിക്കപ്പെടുന്ന ഉറവിടം. പ്രസിദ്ധീകരിച്ച ഓരോ വിവർത്തനത്തിനും അതിൻ്റേതായ ഫയലും പൊതു URL-ഉം ലഭിക്കുന്നതിനാൽ പൗരന്മാർക്ക് ഇംഗ്ലീഷ് എഡിറ്റിംഗ് സ്റ്റാൻഡേർഡ് മാറ്റാതെ തന്നെ അവരുടെ ഭാഷയിൽ BRASA ഉപയോഗിക്കാനാകും.

## ഒരു ബിസിനസ്സ് ആരംഭിക്കുക

പ്രൊഫഷനുകൾ പര്യവേക്ഷണം ചെയ്യുന്നതിനും നിങ്ങളുടെ അക്കൗണ്ട് സൃഷ്ടിക്കുന്നതിനും [ബ്രസ.ബിസിനസ്](https://brasa.business/) സന്ദർശിക്കുക.

സൈറ്റ് സ്റ്റാറ്റിക് HTML, JavaScript ആയി വിന്യസിച്ചിരിക്കുന്നു. ഐഡൻ്റിറ്റി, പേയ്‌മെൻ്റുകൾ, ഇൻവോയ്‌സിംഗ് അല്ലെങ്കിൽ രാജ്യം-നിർദ്ദിഷ്‌ട പാലിക്കൽ എന്നിവയെ ബാധിക്കുന്ന മാറ്റങ്ങൾ റിലീസിന് മുമ്പ് പരിശോധിച്ചുറപ്പിക്കേണ്ടതുണ്ട്.
