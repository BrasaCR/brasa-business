# BRASA ბიზნესი

**უფასო ბიზნესპროგრამა და მოქალაქეთა ბაზარი—ორგანიზებული ყველა პროფესიისთვის.**

[გახსენით BRASA ბიზნესი](https://brasa.business/) · [BRASA მსოფლიო](https://brasa.world/) · [განათლება](https://brasa.education/) · [საჯარო მმართველობა](https://brasagovernment.net/)

BRASA ბიზნესი მოქალაქეებს ბიზნესის დასაწყებად, სამართავად და გასაზრდელად პრაქტიკულ ხელსაწყოებს აძლევს. პლატფორმა მრავალ პროფესიასა და სექტორს მოიცავს და დაკავშირებულია განათლებასთან, საჯარო მომსახურებებსა და თითოეული მოქალაქის ქვეყნის გვერდთან.

## რას იღებენ მოქალაქეები

- უფასო ბიზნესპროგრამას საცდელი პერიოდისა და გამოწერის გარეშე
- სხვადასხვა პროფესიასა და სექტორზე მორგებულ ხელსაწყოებს
- BRASA ID-ს მოქალაქეთა საერთო იდენტობის სისტემის მეშვეობით
- მომხმარებელთა პირდაპირ გადახდებს ისე, რომ BRASA მოვაჭრის სახსრებს არ ინახავს
- კავშირებს სწავლასთან, საჯარო მომსახურებებსა და BRASA-ს ფართო ბაზართან

## მუშაობის პრინციპები

- BRASA მოქალაქეებს ბიზნესპროგრამის გამოყენების დასაწყებად თანხას არ უხდის.
- იდენტობა საერთო რეგისტრაციის მომსახურებით იქმნება.
- BRASA არ მონაწილეობს ბიზნესსა და მის მომხმარებელს შორის გადახდის ნაკადში.
- ქვეყნისთვის დამახასიათებელი გადახდების, გადასახადებისა და ანგარიშფაქტურების შესახებ მტკიცებები გამოქვეყნებამდე უნდა შემოწმდეს.

## ენობრივი ხელმისაწვდომობა

ინგლისური შენარჩუნებულ წყაროს ენად რჩება. თითოეული გამოქვეყნებული თარგმანი საკუთარ ფაილსა და საჯარო მისამართს იღებს, რათა მოქალაქეებმა BRASA თავიანთ ენაზე გამოიყენონ ინგლისური რედაქტირების სტანდარტის შეცვლის გარეშე.

## დაიწყეთ ბიზნესი

BRASA ბიზნესი პროფესიების კატალოგიდან გადაიზარდა მართულ სამუშაო სივრცედ ბიზნესის გასატარებლად. თორმეტი დაკავშირებული ოპერაციული ზონა იზიარებს პირადობას, ნებართვებს, ქვეყნის კონტექსტს, ჩანაწერებს, მტკიცებულებებს და მხოლოდ აუდიტის ისტორიას.
