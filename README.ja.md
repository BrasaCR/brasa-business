# BRASA ビジネス

**あらゆる職業向けに整理された無料の事業ソフトウェアと市民市場です。**

[BRASA ビジネスを開く](https://brasa.business/) · [BRASA 世界](https://brasa.world/) · [教育](https://brasa.education/) · [行政サービス](https://brasagovernment.net/)

BRASA ビジネスは、市民が事業を始め、運営し、成長させるための実用的なツールを提供します。多くの職業と業種を対象にしながら、教育、行政サービス、各市民の国別ページとつながります。

## 市民が受け取るもの

- 試用期間や定期契約のない無料の事業ソフトウェア
- さまざまな職業と業種に合わせたツール
- 共通の市民本人確認システムを通じた BRASA ID
- BRASA が販売者資金を保有しない顧客からの直接支払い
- 学習、行政サービス、BRASA 市場への接続

## 運営原則

- BRASA は事業ソフトウェアの利用開始に料金を請求しません。
- 本人情報は共通登録サービスを通じて作成されます。
- BRASA は事業者と顧客の間の支払い経路に入りません。
- 国別の支払い、税務、請求情報は公開前に確認する必要があります。

## 言語での利用

英語は維持される原文です。公開された各翻訳には独自のファイルと公開アドレスがあり、英語の編集基準を変えずに市民が自分の言語で BRASA を利用できます。

## 事業を始める

[brasa.business](https://brasa.business/) で職業を探し、アカウントを作成してください。

## 保守に関する注意

サイトは静的 HTML と JavaScript として公開されます。本人確認、支払い、請求、国別法令への対応に関する変更は、公開前に確認が必要です。

## 現在のBRASA

BRASAは現在、198の国別ページを教育・政府・ビジネスと結び付けています。BRASA Businessには、販売時点管理と領収書、CRM、在庫、人材と研修、給与と銀行、時間管理、家族支援、法務、政府書式、レポート、共有ワークスペースという12の連携領域があります。オープン台帳、ガイド付きワークフロー、オフライン継続運用も含まれます。

BRASA Financialsは395件の記録から385の決済システムを整理し、161の国・複数国市場の説明と216の決済種類を収録しています。モバイルマネー、即時振込、QR、ウォレット、現金ネットワーク、送金、オープンバンキング、国内カード、USSDなどが含まれます。

掲載は利用開始や承認を意味しません。資金を移動するのは認可を受けた事業者です。各方式には、国と公式情報源の確認、認可、接続、決済テスト、本番承認が必要です。BRASAは確認済みの選択肢を領収書、照合、オープン台帳につなぎます。
