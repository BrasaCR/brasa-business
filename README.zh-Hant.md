# BRASA 商業

**面向每種職業的免費商業軟體和公民市場。**

[開啟 BRASA 商業](https://brasa.business/) · [BRASA 世界](https://brasa.world/) · [教育](https://brasa.education/) · [政府服務](https://brasagovernment.net/)

BRASA 商業為公民提供創辦、經營和發展企業的實用工具。平台涵蓋眾多職業和產業，並與教育、政府服務以及每位公民的國家頁面保持連結。

## 公民獲得的內容

- 無試用期、無訂閱費用的免費商業軟體
- 適用於不同產業和職業的工具
- 透過共用公民身分系統取得 BRASA ID
- 客戶直接付款，BRASA 不持有商戶資金
- 與學習、政府服務和 BRASA 市場的連結

## 營運原則

- 公民開始使用商業軟體時，BRASA 不收取費用。
- 身分透過共用註冊服務建立。
- BRASA 不參與企業與客戶之間的付款流程。
- 與特定國家相關的付款、稅務或開票資訊必須在發布前核實。

## 語言存取

英語仍是持續維護的來源語言。每個已發布的翻譯都有獨立檔案和公共網址，讓公民無需更改英文編輯標準即可使用自己的語言存取 BRASA。

## 開始創業

造訪 [brasa.business](https://brasa.business/)，瀏覽職業並建立您的帳戶。

## 維護說明

網站以靜態 HTML 和 JavaScript 發布。涉及身分、付款、開票或特定國家法規遵循的變更，必須在發布前核實。

## 今天的BRASA

BRASA現已將198個國家目的地與教育、政府和商業連結起來。BRASA Business包含12個互聯領域：銷售與收據、CRM、庫存、人員與培訓、薪資與銀行、時間管理、家庭支援、法律事務、政府表格、報告以及共享工作空間。系統亦包括開放帳本、引導式工作流程和離線持續運作。

BRASA Financials已從395筆記錄中整理出385種支付系統，涵蓋161個國家或多國市場說明以及216種支付類型，包括流動支付、即時轉帳、QR、電子錢包、現金網絡、匯款、開放銀行、本地卡系統和USSD。

被收錄不代表已經啟用。資金由持牌服務商轉移；每種方式都必須經過國家與官方來源核驗、牌照審查、技術整合、結算測試和生產批准。BRASA把經過核驗的選項連接到收據、對帳和開放帳本。
