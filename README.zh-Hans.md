# BRASA 商业

**面向每种职业的免费商业软件和公民市场。**

[打开 BRASA 商业](https://brasa.business/) · [BRASA 世界](https://brasa.world/) · [教育](https://brasa.education/) · [政府服务](https://brasagovernment.net/)

BRASA 商业为公民提供创办、经营和发展企业的实用工具。平台覆盖众多职业和行业，并与教育、政府服务以及每位公民的国家页面保持连接。

## 公民获得的内容

- 无试用期、无订阅费用的免费商业软件
- 适用于不同行业和职业的工具
- 通过共享公民身份系统获得 BRASA ID
- 客户直接付款，BRASA 不持有商户资金
- 与学习、政府服务和 BRASA 市场的连接

## 运营原则

- 公民开始使用商业软件时，BRASA 不收取费用。
- 身份通过共享注册服务创建。
- BRASA 不参与企业与客户之间的付款流程。
- 与特定国家相关的付款、税务或开票信息必须在发布前核实。

## 语言访问

英语仍是持续维护的源语言。每个已发布的翻译都有独立文件和公共地址，让公民无需更改英文编辑标准即可使用自己的语言访问 BRASA。

## 开始创业

访问 [brasa.business](https://brasa.business/)，浏览职业并创建您的账户。

## 维护说明

网站以静态 HTML 和 JavaScript 发布。涉及身份、付款、开票或特定国家合规要求的变更，必须在发布前核实。

## 今天的BRASA

BRASA现已将198个国家目的地与教育、政府和商业连接起来。BRASA Business包含12个互联领域：销售与收据、CRM、库存、人员与培训、工资与银行、时间管理、家庭支持、法律事务、政府表格、报告以及共享工作空间。系统还包括开放账本、引导式工作流程和离线连续运行。

BRASA Financials已从395条记录中整理出385种支付系统，涵盖161个国家或多国市场描述以及216种支付类型，包括移动支付、即时转账、QR、电子钱包、现金网络、汇款、开放银行、本地卡系统和USSD。

被收录不代表已经启用。资金由持牌服务商转移；每种方式都必须经过国家与官方来源核验、许可审查、技术集成、结算测试和生产批准。BRASA把经过核验的选项连接到收据、对账和开放账本。
