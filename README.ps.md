# BRASA سوداګري

**وړیا سوداګریز سافټویر او د وګړو بازار—د هر مسلک لپاره تنظیم شوی.**

[BRASA سوداګري پرانیزئ](https://brasa.business/) · [BRASA نړۍ](https://brasa.world/) · [زده کړه](https://brasa.education/) · [حکومت](https://brasagovernment.net/)

BRASA سوداګري وګړو ته د کاروبار د پیل، چلولو او ودې لپاره عملي وسایل ورکوي. دغه نظام ګڼ مسلکونه او برخې رانغاړي او له زده کړې، عامه خدمتونو او د هر وګړي د هېواد له پاڼې سره تړلی پاتې کېږي.

## وګړي څه ترلاسه کوي

- وړیا سوداګریز سافټویر، پرته له ازمایښتي مودې یا ګډون
- د بېلابېلو مسلکونو او برخو لپاره برابر شوي وسایل
- د وګړو د ګډ پېژند نظام له لارې BRASA ID
- د پېرېدونکو مستقیمې تادیې، پرته له دې چې BRASA د پلورونکي پیسې وساتي
- له زده کړې، عامه خدمتونو او پراخ BRASA بازار سره اړیکې

## کاري اصول

- BRASA له وګړو څخه د سوداګریز سافټویر د کارولو د پیل لپاره پیسې نه اخلي.
- پېژندنه د ګډ نوم‌لیکنې خدمت له لارې جوړېږي.
- BRASA د کاروبار او پېرېدونکي ترمنځ د تادیې په بهیر کې نه داخلېږي.
- د هېواد ځانګړې د تادیاتو، مالیاتو او حسابونو ادعاوې باید تر خپرولو مخکې تایید شي.

## ژبنی لاسرسی

انګلیسي د ساتل کېدونکې سرچینې ژبه پاتې کېږي. هر خپور شوی ژباړل شوی متن خپل فایل او عامه ادرس ترلاسه کوي، څو وګړي BRASA په خپله ژبه وکاروي، پرته له دې چې د انګلیسي سمون معیار بدل شي.

## کاروبار پیل کړئ

د مسلکونو د کتلو او خپل حساب د جوړولو لپاره [brasa.business](https://brasa.business/) ته ورشئ.

## د ساتونکو یادښتونه

وېب‌سایټ د ثابت HTML او JavaScript په توګه خپرېږي. هغه بدلونونه چې پر پېژندنه، تادیاتو، حسابونو یا د هېواد ځانګړي اطاعت اغېز کوي، تر خپرولو مخکې تایید ته اړتیا لري.
