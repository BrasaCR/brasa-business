# BRASA வணிகம்

**ஒவ்வொரு தொழிலுக்கும் ஒழுங்கமைக்கப்பட்ட இலவச வணிக மென்பொருளும் குடிமக்கள் சந்தையும்.**

[BRASA வணிகத்தைத் திறக்கவும்](https://brasa.business/) · [BRASA உலகம்](https://brasa.world/) · [கல்வி](https://brasa.education/) · [அரசுச் சேவைகள்](https://brasagovernment.net/)

ஒரு தொழிலைத் தொடங்கவும் நடத்தவும் வளர்க்கவும் தேவையான நடைமுறைக் கருவிகளை BRASA வணிகம் குடிமக்களுக்கு வழங்குகிறது. பல தொழில்களையும் துறைகளையும் உள்ளடக்கும் இந்தத் தளம் கல்வி, அரசுச் சேவைகள் மற்றும் ஒவ்வொரு குடிமகனின் நாட்டுப் பக்கத்துடன் இணைந்துள்ளது.

## குடிமக்கள் பெறுபவை

- சோதனைக் காலம் அல்லது சந்தா இல்லாத இலவச வணிக மென்பொருள்
- பல்வேறு தொழில்கள் மற்றும் துறைகளுக்கு ஏற்ற கருவிகள்
- பொதுவான குடிமக்கள் அடையாள அமைப்பின் வழியாக BRASA ID
- BRASA விற்பனையாளர் பணத்தை வைத்திருக்காமல் வாடிக்கையாளரிடமிருந்து நேரடி பணப்பரிமாற்றம்
- கற்றல், அரசுச் சேவைகள் மற்றும் BRASA சந்தையுடன் இணைப்புகள்

## செயல்பாட்டுக் கொள்கைகள்

- வணிக மென்பொருளைப் பயன்படுத்தத் தொடங்க குடிமக்களிடம் BRASA கட்டணம் வசூலிப்பதில்லை.
- பொதுப் பதிவுச் சேவையின் மூலம் அடையாளம் உருவாக்கப்படுகிறது.
- வணிகத்திற்கும் அதன் வாடிக்கையாளருக்கும் இடையிலான பணப்பரிமாற்றப் பாதையில் BRASA இருப்பதில்லை.
- நாட்டுக்கே உரிய கட்டணம், வரி அல்லது விலைப்பட்டியல் தகவல் வெளியீட்டுக்கு முன் சரிபார்க்கப்பட வேண்டும்.

## மொழி அணுகல்

ஆங்கிலம் பராமரிக்கப்படும் மூலமாகவே இருக்கும். ஒவ்வொரு வெளியிடப்பட்ட மொழிபெயர்ப்புக்கும் தனி கோப்பும் பொது முகவரியும் கிடைக்கும்; இதனால் ஆங்கிலத் திருத்தத் தரத்தை மாற்றாமல் குடிமக்கள் தங்கள் மொழியில் BRASA பயன்படுத்த முடியும்.
